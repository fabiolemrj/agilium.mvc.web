# Módulo Configurações

## Objetivo

O módulo **Configurações** gerencia parâmetros globais e por empresa que controlam o comportamento do sistema.

---

# Responsabilidades

- Parâmetros globais do sistema
- Configurações por empresa
- Configuração de imagens (logotipos)
- Configuração de e-mail
- Versão do sistema

---

# Principais Entidades

| Entidade | Descrição |
|----------|-----------|
| Config | Parâmetros de configuração |
| ConfigImagem | Imagens/logotipos configurados |
| VersaoSistema | Controle de versão |
