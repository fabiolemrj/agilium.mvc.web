# Módulo Unidades de Medida

## Objetivo

O módulo **Unidades** gerencia as unidades de medida utilizadas para quantificar produtos em compras, vendas e estoque.

---

# Responsabilidades

- Cadastro de unidades de medida
- Vínculo com produtos

---

# Principais Entidades

| Entidade | Descrição |
|----------|-----------|
| Unidade | Unidade de medida (KG, UN, L, etc.) |

---

# Dependências

- Produto
- Empresa

---

# Serviços Envolvidos

- UnidadeService

---

# Controllers Relacionados

- UnidadeController
