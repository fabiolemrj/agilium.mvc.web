# Módulo Funcionários

## Objetivo

O módulo **Funcionários** gerencia o cadastro de funcionários (vendedores, operadores) vinculados à empresa.

---

# Responsabilidades

- Cadastro de funcionários
- Vínculo com empresa
- Vínculo com usuário do sistema (opcional)

---

# Principais Entidades

| Entidade | Descrição |
|----------|-----------|
| Funcionario | Registro do funcionário |

---

# Dependências

- Empresa
- Usuario

---

# Serviços Envolvidos

- FuncionarioService

---

# Controllers Relacionados

- FuncionarioController

---
